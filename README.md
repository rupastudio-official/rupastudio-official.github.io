# Rupa Studio

Situs publik Rupa Studio (GitHub Pages).

- `index.html`: halaman jualan.
- `beta/`: resep beta gratis untuk anggota daftar tunggu (berlabel belum lolos uji).
- `resep/`: halaman resep berbayar. Isinya terenkripsi AES-256-GCM dan hanya terbuka dengan kode akses dari pembelian.
- `konten/`: gambar dan video postingan media sosial.

Tidak berafiliasi dengan Google, OpenAI, maupun Anthropic.
